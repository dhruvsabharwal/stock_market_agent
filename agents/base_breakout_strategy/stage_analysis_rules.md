Part 1: Core System Inputs & VariablesDefine the following baseline variables:Price (C, L, H): Weekly Close (C), Weekly Absolute Low (L), Weekly Absolute High (H).The Trend Filter (SMA30): 30-period Simple Moving Average of the Weekly Close.SMA Velocity (Slope30): The rate of change of the SMA30 (Rising, Declining, Flat).Structural Pivots (PivotLow, PivotHigh): Calculate local minima/maxima using the absolute wicks (L and H) over a 5-week lookback/lookforward window.Dynamic Trendline (Stage2_Line): A calculated line equation ($y = mx + b$). It is drawn by connecting the $x$ (Time) and $y$ (PivotLow price) coordinates of the two most recently confirmed PivotLows. Project this line forward to the current bar.Part 2: The Stage Logic (State Machine)Initialize the system with State = 0 (Unknown). Update the state based on these strictly ordered leading triggers.State 1: Accumulation (The Base)Trigger (The Bleeding Stops): A new PivotLow is confirmed that is $\ge$ the previous PivotLow. (Breaks the Stage 4 lower-low sequence).Action: * Set Stage1_Floor = The exact price of that lowest PivotLow.Set Stage1_Ceiling = The exact price of the first major PivotHigh formed after the floor is established.State Maintenance: Price whipsaws between Floor and Ceiling. Slope30 will naturally decelerate and flatten during this phase.State 2: Advancing Phase (The Markup)Trigger (The Breakout): C closes definitively > Stage1_Ceiling.Strict Confirmations: C > SMA30 AND Slope30 is currently Rising (or strictly not Declining).State Maintenance: The system must continuously update the Stage2_Line ($y = mx + b$) every time a new, higher PivotLow is confirmed.State 3: Distribution (The Top)Trigger (The Trend Break): C closes < the current projected value of the Stage2_Line.Action (Locking the Box):Wait for the immediate downward wave to exhaust. Set Stage3_Floor = The first PivotLow formed after the trendline break.Set Stage3_Ceiling = The PivotHigh of the subsequent bounce.State Maintenance: Price chops between Stage3_Floor and Stage3_Ceiling. (Note: Slope30 will naturally flatten during this phase due to the sideways price action).State 4: Declining Phase (The Markdown)Trigger (The Breakdown): C closes < Stage3_Floor.State Maintenance: The system enters a markdown phase. Wait for a new PivotLow sequence to fail (which will trigger the loop back to State 1).
